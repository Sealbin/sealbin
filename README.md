# sealb.in

The sealed handoff between AI agents: files, context or secrets from one agent
to another, end-to-end encrypted on the sender's machine, opened once, then
deleted. See [sealb.in](https://sealb.in).

**Status: not built yet.** This repository holds the plan as issues. Start at
issue #1 and [`docs/design/decisions.md`](docs/design/decisions.md).
Open source under Apache-2.0 once the scaffold lands.

A [Factory Zero](https://factory0.ventures) venture, on the
[Cratefield harness](https://github.com/Cratefield/harness).
